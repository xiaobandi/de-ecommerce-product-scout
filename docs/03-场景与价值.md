# 03 · 场景与价值

## 谁在用

有数据意识的腰部卖家（约占 20-30%，据R3调研）

## 三个典型场景

### 场景 A：类目热词与趋势采集
- **触发**：定时（每日）
- **之前**：人工从头做一遍，每次口径不一、结果不可比
- **之后**：热词→趋势曲线→机会标记
- **收益**：月省盯盘 10h≈¥300

### 场景 B：竞品上架/价格/销量监控
- **触发**：定时（每 2 小时）
- **之后**：竞品动态→异动摘要推送
- **收益**：跟款窗口从周级缩到小时级

### 场景 C：蓝海关键词挖掘
- **触发**：定时（每周）
- **之后**：搜索量/竞争度→机会评分
- **收益**：避开同质化价格战（P8）

## 价值构成

| 维度 | 说明 |
|---|---|
| 省时间 | 对标蝉妈妈专业版年费 1.2 万（据R5调研）；月省 12h≈¥360 |
| 提一致性 | 同一能力固化成技能，口径不再因人而异 |
| 降风险 | 业务红线写死在提示词里，越界即停 |
| 可审计 | 每个数字可回指输入，产出可追溯 |

## 与人工的边界

本员工**不替代决策**。它负责把重复劳动做成清单与初稿，
把决策点（要不要发、要不要改价、要不要道歉）留给人。
