# 使用示例

技能：**价格监控**（`wf-ecom-scout-price-monitor`）

> ⚠️ **本技能的真实效果示例尚未补齐**：以下仅为输入 / 输出契约（**不构成效果证据**）与平台兼容性验证结果。发布前须补至少 3 组「真实输入 → 实际产出」。

---

## 示例一 · 标准用法（真实运行）

```bash
python3 ../../tools/anomaly_detect.py --file examples/input/metrics.json
```

**真实输出**：

```console
异常检测（全序列扫描；基线=前 6 期中位数+MAD，双门槛：幅度≥20.0% 且 z≥2.0）：2 个指标，命中 1 条，涉及 1 个时间点

【成交价】
  正常，无异常

【可比价】
  [P2] 连续趋势 — 第 2 期 起连续 4 期下降，关注是否形成拐点
```

> 价格序列突变被自动标出，避免人工盯表漏掉竞品调价

> **注意**：k 值决定灵敏度：调太低会把大促日误报成异常，节庆周期要单独设阈值。

---

## 示例二 · 用你自己的材料

```bash
python3 ../../tools/anomaly_detect.py --file /path/to/your-data/metrics.json
```

把 `examples/input/` 下的文件换成你的真实材料即可；**输入结构不要改**，改了字段名脚本会读不到。

---

## 示例三 · 嵌进自动化链路

```bash
set -e
python3 ../../tools/anomaly_detect.py --file examples/input/metrics.json || exit 2   # 非零即阻断
```

脚本是纯函数：文件/stdin 进、stdout 出、退出码表达判定，因此可以被 CI、定时任务或上层工作流直接编排。
