# 蓝海关键词挖掘 · 架构与流程图

## 本工作流的四层结构

```mermaid
flowchart TB
  U["使用层：选品与竞品情报 的使用者"]
  T["触发层：蓝海关键词挖掘"]
  X["执行层：2 个步骤"]
  O["产出层：机会评分"]
```

| 层 | 内容 |
|---|---|
| 使用层 | 有数据意识的腰部卖家（约占 20-30%，据R3调研）；员工定位：选品分析师·小察 ｜ 给结论不给仪表盘，把生意参谋/蝉妈妈翻译成决策 |
| 触发层 | 关键词 / 显式点名「蓝海关键词挖掘」；触发方式：定时（每周） |
| 执行层 | 搜索量/竞争度 → 机会评分 |
| 产出层 | 机会评分 |
